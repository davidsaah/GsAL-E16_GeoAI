# Accessibility Checklist

- Use a logical reading order in slides and documents.
- Provide alt text or equivalent descriptions for meaningful images, maps, charts, and diagrams.
- Meet WCAG AA contrast targets for text and meaningful graphical elements.
- Do not communicate meaning through color alone.
- Use readable type sizes and avoid dense text.
- Expand acronyms on first use.
- Define technical language in plain terms.
- Caption video and provide transcripts for essential audio.
- Ensure instructions do not depend only on screenshots.
- Provide text equivalents for interactive or animated explanations.
- Use descriptive link text.
- Provide keyboard-accessible browser activities when possible.
- State accessibility limitations and provide equivalent alternatives.
- Test exported PDFs and slide files for reading order and selectable text.
- Avoid flashing, rapid animation, and unnecessary motion.
